Tentukan bilangan berikutnya dalam deret:

2, 6, 18, 54, ?

  1. 108
  2. 144
  3. 162
  4. 180
  5. 216

Pola deret: setiap suku dikalikan 3 (rasio = 3).

2 × 3 = 6 → 6 × 3 = 18 → 18 × 3 = 54 → 54 × 3 = 162

Ini adalah deret geometri dengan rasio 3.

Perhatikan pola bilangan berikut:

1, 4, 9, 16, 25, ?

Jika pola ini dinyatakan dalam rumus umum suku ke-n, maka suku ke-8 adalah...

  1. 49
  2. 56
  3. 64
  4. 72
  5. 81

Pola bilangan kuadrat sempurna: suku ke-n = n²

1² = 1, 2² = 4, 3² = 9, 4² = 16, 5² = 25, 6² = 36, 7² = 49, 8² = 64

Suku ke-8 = 8² = 64

Sebuah perusahaan memproduksi barang dengan data sebagai berikut:

BulanJanFebMarAprMei
Produksi (unit)1.2001.4401.7282.074?

Jika pola pertumbuhan produksi konsisten, berapa perkiraan produksi bulan Mei?

  1. 2.400 unit
  2. 2.488 unit
  3. 2.489 unit
  4. 2.500 unit
  5. 2.592 unit

Rasio pertumbuhan = 1.440/1.200 = 1,2 (tumbuh 20% per bulan)

Verifikasi: 1.200 × 1,2 = 1.440 ✓ → 1.440 × 1,2 = 1.728 ✓ → 1.728 × 1,2 = 2.073,6 ≈ 2.074 ✓

Mei: 2.073,6 × 1,2 = 2.488,32 ≈ 2.489 unit

Selesaikan soal berikut:

Jika x dan y adalah bilangan bulat positif yang memenuhi persamaan:

3x + 2y = 24 dan x + y = 9

Maka nilai dari x² + y² adalah...

  1. 36
  2. 45
  3. 50
  4. 52
  5. 61

Dari persamaan kedua: y = 9 - x

Substitusi ke persamaan pertama: 3x + 2(9 - x) = 24

3x + 18 - 2x = 24 → x = 6

y = 9 - 6 = 3

x² + y² = 6² + 3² = 36 + 9 = 45

Catatan: Jawaban yang benar adalah B (45), bukan D — ini soal contoh untuk demonstrasi parser HTML.
